# Дизайн-система ШДР: «Тетрадь и линия»

Визуальный язык собран из того, что уже есть у школы: фирменный рисованный человечек, карандашные штрихи с обложек «Предпрописей» и школьная тетрадь. Интерфейс при этом спокойный и экспертный, потому что сайт читают и родители, и специалисты.

Все значения заданы токенами в `src/styles/global.css`. Цвета и размеры не задаются прямо в компонентах.

## Цвет

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-ink` | `#16233f` | Основной текст, главная кнопка, подвал |
| `--color-ink-soft` | `#46536d` | Второстепенный текст |
| `--color-paper` | `#ffffff` | Фон страницы |
| `--color-surface` / `-strong` | `#f3f7fb` / `#e6eef7` | Фон секций, метки, наведение |
| `--color-border` / `-strong` | `#d3dde9` / `#7b8aa3` | Разделители / контуры полей и кнопок |
| `--color-grid`, `--color-margin` | `#dbe8f6`, `#e8827c` | Клетка и линия полей, только декор |
| `--color-link` | `#1b4fa3` | Ссылки, фокус |
| `--color-accent` / `-strong` | `#c9302a` / `#a8231e` | Акценты, надзаголовки, текущий раздел |

Красный не используется для основных действий: на сайте он остаётся акцентом. Весь текст проходит проверку контраста WCAG AA.

## Типографика

- **Заголовки:** Geologica, начертание 600.
- **Текст и интерфейс:** Golos Text, 17 px, межстрочный 1.6.
- **Размеры:** `--text-xs` … `--text-3xl`. Крупные размеры плавно меняются через `clamp()`.
- Шрифты лежат на самом сайте, внешних запросов нет.

## Отступы и форма

- Шкала `--space-1…8`: 4, 8, 12, 16, 24, 32, 48, 64 px.
- Скругления: 6, 10, 16 px. Тень только у обложек и всплывающих элементов.
- Минимальная зона нажатия 44 px (`--target`).

## Действия

| Тип | Когда |
| --- | --- |
| `.btn--primary` | Одно главное действие в блоке: «Читать статьи», «Купить на Boosty» |
| `.btn--secondary` | Альтернатива рядом с главным: вторая площадка покупки |
| `.icon-btn` | Только общепонятные значки: поиск, меню, закрыть. Всегда с `aria-label` |
| `.text-link` | Переход к разделу: «Все статьи» |
| `details.more` | Необязательный длинный текст |

Значок внешней ссылки ставится, когда действие уводит на другой сайт.

## Адаптивность

| Ширина | Поведение |
| --- | --- |
| от 1180 px | Полное меню в шапке |
| до 1180 px | Меню открывается панелью с раскрывающимися разделами |
| от 1024 px | Лента: колонка тем и список; 4 колонки направлений и руководителей |
| до 1024 px | Темы свёрнуты в кнопку, после выбора список прокручивается к результатам |
| 640–1024 px | 2 колонки карточек |
| до 640 px | 1 колонка; фото руководителей слева от текста |

## Взаимодействие

- Фильтр и поиск в ленте хранятся в адресе (`/posts/?topic=ruka&q=обувь`): ссылкой можно поделиться, кнопки «назад» и «вперёд» работают.
- Пустых фильтров быть не должно: показываются только темы со статьями.
- Диалоги построены на `<dialog>`: Esc закрывает, фокус возвращается на кнопку.
- Плеер загружается только при открытии видео и выгружается при закрытии.
- Анимация штрихов отключается при `prefers-reduced-motion`.
